# 06. Deployments and DevOps

## Folder purpose

Local environment configuration, build/release automation, monitoring, and operational procedures.

## Current status

No hosting or deployment target is approved. Android is the first intended platform.

## Plan

1. Define local setup and emulator configuration before connecting backend services.
2. Confirm platform support, environment ownership, release process, monitoring, and incident response.
3. Add build/release automation only after the target and maintainers are known.
4. Keep secrets in approved secret storage and out of the app bundle and Git history.
5. Deploy only with explicit authorization for the named environment and action.

## Ready when

Owners approve the target, release process, operational responsibilities, and rollback approach.
